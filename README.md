# Databases Deep Dive Core Notes

A single-page revision guide for practical database engineering concepts, including SQL, MongoDB, indexing, transactions, replication, scaling, and sharding.

![Databases Deep Dive Core Notes screenshot](screenshot.png)

## Features

- Topic-based study guide with focused database notes
- Practical mental models for SQL and NoSQL design
- Notes on indexes, schema design, joins, transactions, replication, and scaling
- Dark and light themes with persistent preference
- Responsive fixed study navigation and go-to-top control

## Tech stack

React, Vite, styled-components, React Icons, and CSS.

## Run locally

Run npm install, then npm run dev. Use npm run build to create a production build and npm run deploy to publish it to GitHub Pages.
